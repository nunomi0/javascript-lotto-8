# javascript-lotto-precourse
## 구현 기능
- [x] 로또 구입 금액 입력
  - [x] 1,000원 단위로 나누어 떨어지지 않는 경우 예외 처리
- [x] 당첨 번호 입력
  - [x] 중복되지 않는 1~45 사이의 숫자 6개
- [x] 보너스 번호 입력
- [x] 구입한 금액 만큼 로또 발행
  - [x] 각 로또에서는 중복되지 않는 1~45 사이의 6개의 숫자 추첨
  - [x] 로또 번호 오름차순으로 정렬하여 출력
- [x] 당첨 내역 계산 및 출력
- [x] 수익률 계산 및 출력
  - [x] 소수점 둘째 자리에서 반올림
- [ ] 사용자가 잘못된 값을 입력할 경우 에러 문구 출력 및 해당 지점부터 다시 입력

## 프로그래밍 요구 사항
- [ ] 들여쓰기 <= 2
- [ ] Jest를 활용한 단위 테스트 (UI 로직은 제외)
- [ ] 함수의 길이가 15라인을 넘어가지 않도록
- [ ] else 지양 (return 사용)
